## 📖 简介
发送**/nai**查看帮助
本插件为 AstrBot 带来了强大的 **NovelAI** 绘图能力。它不仅仅是一个简单的 API 调用工具，还集成了 **LLM 辅助生图**、**自动绘图**、**额度管理**、**队列系统**以及 NovelAI 的高级功能（如氛围转移 Vibe Transfer、角色保持 Character Keep）。

支持 **Opus 免费模式**（小图模式），订阅用户可无限畅玩。

## ✨ 特性

- **🎨 多种绘图模式**：
    - **基础模式** (`nai`)：直接使用 Prompt 标签绘图。支持批量出图限制。
    - **智能模式** (`nai画图`)：使用自然语言描述，由 LLM 自动生成专业标签和参数。支持上传参考图。
    - **自动模式** (`nai自动画图`)：监听对话上下文，自动为群友的聊天内容配图。支持上传参考图。
    - **批量生图扩展**：智能模式与自动模式均支持批量生图（通过 `n=` 指定），且每张图都会重新调用 LLM 独立生成参数以保证多样性。
- **🖼️ 高级功能支持**：
    - **图生图 (i2i)**：支持引用图片进行重绘。
    - **氛围转移 (Vibe Transfer)**：提取参考图的风格/构图。内置 **Vibe 缓存机制**，复用图片时直接调用缓存，避免连续扣费。
    - **角色保持 (Character Keep, CS)**：支持创建角色档案（`cs`），并在绘图中通过 `cs=角色名` 快捷引用，保持角色特征一致性（支持多角色组合）。
    - **多角色控制 (Role)**：指定不同区域角色的外貌。
    - **视觉识图与消息引用**：支持多模态模型识别发送的图片并生成参数。**全面支持收集被引用消息里的图片**（手动绘图、自动绘图和 LLM 工具入口均已接入）。
    - **多图参考（可选）**：同一条消息里发送多张图，除被消耗的图片外，其余会传给高级参数模型（可用 `llm.vision_image_limit` 限制数量）。
    - **预置图库系统**：内置云端图库，`i2i`、`vibe_transfer`、`character_keep` 均可直接通过 `图库名称` 快捷调用，无需每次发送图片。
    - **模型支持**：支持最新的 nai5 模型选择。
- **⚙️ 强大的系统管理**：
    - **默认预设回退逻辑**：若无正/负向提示词，系统会优先读取是否预存了预设，若无则读取默认提示词配置（有提示词则覆盖）。
    - **资源隐私与预览**：预设、图库、角色保持（CS）数据支持按用户隔离（可配置是否公开所有用户的资源，或设置普通用户查看权限与资源管理员）。新增资源预览图功能，无预览图时自动提取第一次生成的图片。
    - **队列与缓存系统**：并发控制防过载，新增独立缓存管理器，针对不同模型、图片内容进行精准哈希隔离，防止跨模型误用缓存和吞图问题。
    - **额度经济**：支持每日签到、额度限制、批量生成上限，角色保持等高级功能同样受额度系统管理，防止滥用。
    - **完整记录反馈**：可配置在使用预设生成后，发送完整的参数记录（包括原始指令、最终提示词、参数和预览图）。

## 📦 安装

1. 确保你已经安装了 [AstrBot](https://github.com/Soulter/AstrBot)。
2. 将本插件文件夹放入 AstrBot 的 `data/plugins/` 目录下。
3. 安装依赖：
   ```bash
   pip install cookit[pydantic] jsonref
   # 可选：如果需要将帮助文档渲染为精美图片
   pip install pillowmd
   ```
4. 重启 AstrBot。

## 🔧 配置

在 AstrBot 管理面板或插件配置文件中进行设置：

| 配置项 | 说明 | 必填 |
| :--- | :--- | :--- |
| `general.merge_draw_to_chat_record` | 是否将画图结果合并为聊天记录（关闭后直接发送单张图片）。 | ❌ 否 |
| `general.send_generation_details` | 默认是否输出完整参数记录；绘图指令中的 `data=true` 可单次开启。 | ❌ 否 |
| `general.public_resources` | 预设、图库、角色保持(CS) 是否对所有人公开。 | ❌ 否 |
| `general.allow_view_all` | 是否允许普通用户查看全部资源（用于保护隐私）。 | ❌ 否 |
| `request.proxy_url` | 画图接口（如 image.novelai.net）的代理地址。非海外机器必填。支持 `http://`、`https://`、`socks5://` 等。 | ❌ 否 |
| `request.tokens` | **授权 Token 列表**。请使用官网获取的 `pst-` 开头的 Token，支持多 Token 轮询。 | ✅ 是 |
| `request.opus_free_mode` | **Opus 免费模式**。开启后强制限制图片尺寸和步数，Opus 账号不扣点数。 | ❌ 否 |
| `llm.advanced_arg_generation_provider` | 用于将自然语言转换为绘图参数的 LLM 模型提供商。 | ❌ 否 |
| `llm.enable_vision` | 是否启用视觉输入（需要模型支持 Vision），用于参考图分析。 | ❌ 否 |
| `quota.enable_quota` | 是否启用额度/签到系统。 | ❌ 否 |
| `quota.max_batch_n` | 单次批量生成（n参数）的最大上限限制。 | ❌ 否 |

## 📁 插件数据目录结构

插件的所有数据默认存储在 `AstrBot/data/plugin_data/astrbot_plugin_ppnai/` 目录下：

```text
astrbot_plugin_ppnai/
├── presets.json                  # 预设数据文件
├── cs/                           # 角色保持(Character Keep)数据
│   └── <用户ID>/
│       └── <CK名称>.txt
├── image_library/                # 预置图库
│   ├── index.json                # 图库名称、文件和 MIME 信息映射
│   └── images/
│       └── <sha256>.bin          # 图库原图
├── previews/                     # 资源预览图缓存
│   ├── index.json                # 资源与预览图的对应关系
│   └── images/
│       ├── preset_*.png          # 预设的预览图
│       ├── ck_*.png              # 角色保持的预览图
│       └── image_*.png           # 图库内容的预览图
└── image_cache/                  # 运行期图片缓存（避免吞图与重复扣费）
    ├── index.json                # 缓存索引
    ├── vibe_inputs/              # 氛围转移参考图缓存
    └── generations/              # AI 生成的最终图片缓存
```

## 🤖 推荐 LLM（高级参数生成）

`nai画图` / `nai自动画图` 会调用指定的 LLM 来生成高级绘图参数（共享全局 HTTP Client，稳定高效）。

- **推荐：`deepseek-chat`**（文本模型，输出稳定，也可做识图参考）
- **推荐：`gemini-3-flash`**（多模态模型，适合开启 `llm.enable_vision=true` 做识图参考）

> **提示：** 建议修改 `src/prompts/advanced.txt` 中的系统提示词，并配置 `llm.regex_replacements` 去除 Markdown 代码块，以保证 JSON 输出的绝对稳定。

## 📝 高级参数示例

在指令或预设中，你可以使用以下高级参数（支持换行）：

**1. 氛围转移 (Vibe Transfer) 结合图库**
```text
nai 1girl
vibe_transfer=图库中保存的名称
vibe_transfer_info_extract=0.8
```
*(注：`vibe_transfer` 和 `character_keep` 不能在同一次请求中同时使用，此为官方限制)*

**2. 角色保持 (Character Keep)**
支持直接引用已存的角色：
```text
nai 动作描述, 背景描述
cs=角色存档名称
```

**3. 批量生成（智能模式）**
```text
nai画图 
ds=帮我画一个赛博朋克风格的城市，要下雨
n=3
```
*(每次生成均会重新通过 LLM 构思不同的细节参数，并扣除对应额度)*
